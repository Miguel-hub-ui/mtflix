iPhone / iPad

Apple only allows this without the App Store via Safari's home screen install:

  1. Open mtflix.site in Safari
  2. Tap Share → Add to Home Screen
  3. Tap Add — launches full-screen, no browser bar
Open MTFlix in Safari

These aren't published on the Play Store or Microsoft Store, so Android and Windows will show a one-time "unknown source" / "unknown publisher" warning during install — that's expected for apps distributed directly. Both installs are thin wrappers around mtflix.site, so they always show whatever's currently live.
